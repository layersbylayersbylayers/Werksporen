LARS KRAMER — PORTFOLIO ADMIN

MAC: dubbelklik START-PORTFOLIO-ADMIN.command
WINDOWS: dubbelklik START-PORTFOLIO-WINDOWS.bat
Sta bij een Windows Firewall-vraag toegang via een particulier netwerk toe.

Login: admin / admin
Wijzig daarna je wachtwoord onder ACCOUNT.

IPAD / IPHONE
Start eerst de admin op je Mac of Windows-computer. Zorg dat beide apparaten op
dezelfde wifi zitten. Open daarna op je telefoon/tablet het wifi-adres dat in
het servervenster verschijnt, bijvoorbeeld http://192.168.1.25:4173/admin.
De computer en het servervenster moeten aan blijven.

Publieke website: http://127.0.0.1:4173/portfolio
Alle opgeslagen instellingen en uploads blijven in deze SSD-map.
Gebruik EXPORT af en toe als extra reservekopie.
